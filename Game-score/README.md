# ゲームスコア記録アプリ 🎮

複数人でのゲームスコアを簡単に記録・管理できるWebアプリです。カードゲーム、ボードゲーム、eスポーツなど、様々なゲームのスコア管理に対応しています。

## 🎯 機能

- **複数人対応**: 1～10人まで同時にスコア管理可能
- **リアルタイム表示**: 進行中のゲームの現在スコアをリアルタイムで表示
- **スコア倍率設定**: 最終スコアに倍率を適用（例：1勝100点 × 2倍 = 200点）
- **スコア履歴**: 各ゲームのスコア記録を保持
- **ランキング表示**: ゲーム終了時に最終スコアで自動ランキング表示
- **モバイル対応**: スマートフォンで快適に利用可能
- **ローカルストレージ対応**: ブラウザのストレージでデータを保存

## 🚀 使い方

### 1. アクセス
GitHubPagesで公開されているURLにアクセス

### 2. プレイヤー数設定
- プレイヤー数を入力（1～10人）
- 「確定」ボタンをクリック

### 3. プレイヤー名入力
- 各プレイヤーの名前を入力
- 「ゲーム開始」をクリック

### 4. スコア倍率設定
- 最終スコアに適用する倍率を入力（デフォルト：1倍）
- 例）1勝の価値が通常の2倍の場合：2を入力
- 「ゲーム開始」をクリック

### 5. ゲーム進行
- 各プレイヤーのスコアを入力
- 「スコア記録」をクリック
- リアルタイムでスコア合計が更新される
- 繰り返し（複数ゲーム可能）

### 6. ゲーム終了
- 「ゲーム終了」をクリック
- 最終スコアと順位が表示される

### 7. 再スタート
- 「もう一度」をクリックして新規ゲーム開始

## 💡 使用例

**カードゲーム「大富豪」での利用:**
- プレイヤー数: 4人
- スコア: 1位=100点、2位=50点、3位=20点、4位=-100点
- 倍率: 3倍（3ゲーム実施予定）
- 各ゲームのスコアを入力 → 最後に合計が自動計算 × 3倍で表示

## ⚙️ 環境設定

このアプリはフロントエンドのみで動作します。インストールは不要です。

**GitHub Pagesで公開するには:**

1. GitHubリポジトリの Settings → Pages に移動
2. Source: Branch を `main` に設定
3. 数分後、提供されたURLで公開されます

## 🔒 プライバシー

すべてのデータはブラウザのローカルストレージに保存されます。サーバーへの送信は一切ありません。

## 🐛 トラブルシューティング

**スコアが保存されない場合:**
- ブラウザのストレージが有効か確認
- シークレットウィンドウではなく通常ウィンドウで開く

**画面が表示されない場合:**
- キャッシュをクリアして再読み込み
- ブラウザのデベロッパーコンソールでエラーを確認
